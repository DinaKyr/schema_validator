# Schema Validator

This repository contains a **JSON schema validator** designed to test the correctness of AI agents’ output against a ground truth.

---

## Overview

The main goal of this project is to **compare JSON outputs** generated by AI agents with the expected results, using a ground-truth implementation.
The validation_request.json provides a structure of 
```
{ schemas : [ {schema1 with details} , .. , {schemaN with details} ] ,
  documents : [ {document1 with details} , .. , {domumentN with details} ]
}
```
- The **ground truth** is implemented in `grader.py`.
- The **AI agent outputs** are evaluated via tests run in **apex-arena**, an environment provided by the interview platform.  

> **Note:** Apex-Arena is not included in this repository. This repository only contains the solution and supporting files necessary to run the grader locally or integrate with Apex-Arena.

# Produces the following validation shema
```
{
  "validation_results": [
    {
    "document_id": the document id,
    "schema_id": the schema id,
    "valid": true/false,
    "errors": ["path": "$.path",
               "message": Description,
              "constraint": type of error,
              "expected": excected value,
              "actual": actual value given
              ] ... or empty list if no errors
    },...
  ],
  "summary": {
  "total_documents": int,
  "valid_documents": int,
  "invalid_documents": int,
  "total_errors": int,
  "errors_by_constraint": {
    "type": int,
    "required": int,
    "format": int,
    "minimum": int,
    "pattern": int,
    "enum": int,
    "uniqueItems": int,
    "additionalProperties": int
    }
  }
}
```
